Technical details

Diagnostic port route, not native engine capture. Original indices use the port dump palette and index-0 transparency; original executable palette/compositing is not yet verified. Both views use logical coordinates at 2× resolution, plus the selected display zoom.

Magenta rectangle: original runtime canvas. Artwork outside it remains visible in this padded review and would be clipped by that canvas. Common scale 0.1 and the same upper-cap measurement rule apply to every pose. No silhouette fitting, warping or interpolated poses.

The recorded B-to-A route contains 23 draws at a nominal 120 ms each. Repeat jumps back to the first recorded draw; it does not invent a return walk. Actual route completion also uses waiting frame 018, which is outside this six-pose review. Anatomy, contact and motion still require human assessment.
