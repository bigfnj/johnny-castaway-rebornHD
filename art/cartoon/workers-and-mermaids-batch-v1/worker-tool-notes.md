# Worker tool poses 072–086

These 15 drawings are appearance drafts for human review. Native scale, registration and motion have not been tested. The approved corrected worker 026 supplies identity and materials only. Each exact original supplies the pose. The source-reading notes were completed before generation in `build/liliputs-next-source-notes.md`, with enlarged exact-source contacts in `build/liliputs-next-source/`.

The source family moves from bent-arm stance 072 through a low leftward crouch 073–076, then an overhead-to-low tool action 077–081, rising/standing turns 082–085 and the rope pull 086. This is a visual grouping, not a claimed playback order. `character-inventory-v1/scene-map/resource-map.json` associates 086–101 with GJGULIVR.TTM tag 61, "TYING JOHNNY DOWN". It does not independently attribute 072–085 or prove native timing.

All requests were saved before their built-in ImageGen call. The corresponding PNGs are untouched byte copies, and per-version records bind request, references, raw cache path, output SHA-256 and alpha statistics. Prior versions remain retained. There are 21 raw/request/record sets for these 15 frames. No export or production package changed.

The selected 15 were inspected beside originals and on both light and dark alpha-composited backgrounds. Every selected file is RGBA with alpha range 0–255. Edge alpha maximum is 0 except 072, 078 and 086 where it is 1; no meaningful clipping or visible halo remains. The selected 086 rope begins well inside its canvas, with alpha8 bounds starting at y=128. The source 077 contains one isolated blue pixel below-left; the generated drawing omits that microdetail rather than interpreting it as an extra limb. Tiny source head blocks do not resolve individual pupils, so gaze interpretation remains an appearance-review question rather than a source-palette measurement.
