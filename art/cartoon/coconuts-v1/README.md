# Cartoon coconut family drafts

Seven new raw images are ready for [visual review](review.html): four coconut orientations and three separate shadows. The user has not approved this group yet. The coconuts use the existing approved palm's brown material; shadows use the existing approved palm shadow as their color reference.

Exact built-in ImageGen requests and returned PNGs are saved under `generation/`. Original references, HD comparisons, a geometry guide and source identities are under `reference/`. [Preflight](preflight.md) documents the fixed runtime canvases, intentionally empty registration columns and independent coconut/shadow script positions.

This is an art-only checkpoint under the [current workflow](../../../docs/cartoon-art-build-workflow.md). Basic image dimensions, mode and alpha range were checked, and the complete raw images are shown for appearance review. Requested output sizes and shapes are guidance only: every returned image is 1254 square, coconut proportions vary somewhat, and the shadows are flatter than the original reference silhouettes. Final uniform-scale export registration, visual size consistency, shadow footprint and motion remain to be resolved during integration. No production package or engine code was changed; full smoke/regression/audit is deferred.
