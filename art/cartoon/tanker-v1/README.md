# Tanker and close-up hull artwork

This family contains appearance-review drafts for all 14 `TANKER.BMP` slots, 000-013, and both `GJPROW.BMP` slots, 000-001. They belong to the 37-slot ship review. Both GJPROW drawings have appearance approval; the tanker awaits motion review. Final runtime sizing and native validation remain pending. No production archive, ledger or runtime has changed for this artwork.

The user subsequently approved both GJPROW drawings with the other non-tanker artwork, while requesting [tanker motion comparison](../tanker-motion-v1/README.md). All14 TANKER drawings remain pending. The comparison uses76 original script draws and exposes end-on proportion and006 perspective concerns; no art has been changed during that investigation.

The exact source references and their hashes are in [reference/source.json](reference/source.json). `reference/original/<resource>/<frame>.png` retains the original reference ZIP member bytes and alpha. `reference/nearest8/` is an integer nearest-neighbor enlargement; `reference/hd/` contains the current bundled HD reference, kept separate from original geometry. The original colors use the port's diagnostic palette and are not a calibrated claim about original executable colors. The two contact sheets compare full original and HD canvases without replacing either source.

`TANKER.BMP` is a rotation family. Frame 000 is a broad, nearly symmetrical end-on view with a crosswise structure whose physical identity is unconfirmed; frame 007 is near the long bow-left profile; later frames turn toward the broad bow-facing 013. `GJPROW.BMP/000` is a cropped red hull panel bearing a light-gray anchor, while 001 is an anchorless tapered hull continuation. These close-ups intentionally retain clipped-piece boundaries rather than becoming complete ships.

The shared material keys are [TANKER 000](generation/TANKER.BMP/000-generated-v1.png) and [TANKER 007](generation/TANKER.BMP/007-generated-v1.png): saturated red steel, pale ivory/light-gray structure, a red funnel with black cap, dark outlines and restrained cel shading. The approved boat supplied the initial drawing-style context, not its motorboat identity. Each generated asset uses its own original geometry reference. Exact built-in image-generation requests are retained beside the untouched output PNGs; per-frame records bind ordered references, source hashes, actual dimensions, alpha measurements and basic visual observations. The batch review manifest chooses versions explicitly; preserved earlier drafts are not silently overwritten.

The current review selection is TANKER v2 for 003-006 and 010-012, with v1 for 000-002, 007-009 and 013; both GJPROW slots use v1. The initial TANKER 003-006 drafts are preserved after the compact gantry correction. Initial 010 and 011 were too side-on, and 012 was insufficiently frontal. A single targeted v2 pass used each exact original plus the 013 bow key, avoiding the strong 007 broadside reference. The corrected 010 has a larger facing bow and shorter receding side, 011 has a dominant foreground bow, and 012 is nearly frontal. All v1 requests, images and observations remain intact.

Frames 008 and 009 remain close to a broadside, while 013 reads as the intended symmetrical bow. The corrected group is ready for appearance comparison, but exact original contours, inter-frame yaw spacing and animation continuity are not established. The original source comparisons should remain available in the human review.

All nine initial outputs for TANKER 007-013 and GJPROW 000-001, plus the three perspective corrections, are RGBA and retain generated alpha without cleanup. TANKER 007 v1 and 011 v2 have faint alpha 1 at the lower raw edge. The GJPROW drafts have nonzero alpha at intended clipped panel boundaries. These are raw-art facts, not a final fit or seam pass. There were no programmatic painting, color normalization, runtime exports or bulk test runs; only image inspection and size, mode, hash and alpha readback.
