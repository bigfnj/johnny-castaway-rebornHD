# Preserved reference mapping

`preparation.json` is the exact, immutable input pinned by the017 exporter.
It binds the native original017, its exact nearest-neighbor enlargement, and
the deterministic reflection of the approved Calm focus024 style reference.
No artistic image edits were performed by the preparation helper.

`prepare_key_snapshot.py.txt` is a historical script snapshot, not a runnable
entry point at this preserved location. It originally ran as
`build/front-arrival/prepare_key.py` from the repository checkout. Its
`parents[2]` root calculation depends on that original location. It requires
the separately prepared scratch `build/front-arrival/reference/metadata.json`
and native/enlarged017 images, and refuses an existing authoring reference
directory. Do not run it from here or remove the stored references to rerun it.
The preserved PNGs and preparation record are sufficient for candidate export.

`original-observations.md` retains the original analyst notes byte-for-byte.
Paths within those historical notes were relative to the local scratch folder
`build/front-arrival/reference`, not this preserved directory.

| Scratch name in the notes | Preserved equivalent or status |
| --- | --- |
| `arrival017-source.json` | `original-source-verification.json` |
| `native/017.png` | `017-original-native.png` |
| `nearest8/017.png` | `017-original-nearest8.png` |
| `metadata.json` | Local scratch; selected017 facts are retained in `preparation.json`. |
| Mirrored original and family/comparison contact sheets | Local scratch diagnostic views, not exporter inputs or generated artwork. |

Original indexed pixels and their source identities determine geometry. Their
diagnostic palette and transparency interpretation are documented limitations;
they do not claim original-executable color calibration.
