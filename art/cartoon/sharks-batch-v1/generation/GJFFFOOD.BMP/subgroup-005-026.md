# GJFFFOOD source-pose subgroup

Twelve built-in imagegen outputs are ready for appearance review: 005, 006, 008, 015, 017, 020, 021, 022, 023, 024, 025 and 026. Proposed selected version is v1 for every slot. The separately authored 019 shared key was not redrawn.

Each exact original nearest8 guide and the shared 019 key was visually inspected before generation. The saved per-frame request names the original as the pose/expression authority and 019 only as the identity/materials reference. One built-in call produced each drawing. Output PNGs are untouched byte copies of the tool cache; records bind the saved requests, ordered input references, output hashes and cache paths.

Visual readback retained the major source actions: 005 submerged rounded head, 006 steep up-left open-mouth lunge, 008 rolled arch with downward open mouth, 015 steep head-down dive, 017 raised-tail curl, 020/021 low trailing tails, 022 closed-eye reaction, 023 raised head, 024 closed-eye open-mouth reaction, 025 grimace and 026 upright surprised head. These are interpreted Cartoon drawings, not pixel-identical silhouettes or measured animation parity. No gross facing/roll failure was identified in this light review, and no v2 calls were made.

Every PNG is RGBA with alpha range 0-255. All alpha >=8 lies inside its raw canvas. Faint edge alpha is preserved unchanged: maximum 1 on 005, 006 and 026; maximum 3 on 024; zero on the other eight. Any colored fringe seen against the tool's black display has not been repainted or keyed away. Attached water is rendered as white/pale-blue foam rather than dark floor shadows.

Basic file readback checked all 12 output/request/reference hashes and exact cache copies. Final source registration, runtime dimensions, native motion and human appearance acceptance remain pending. No runtime exports, production archive changes or full tests were performed.
