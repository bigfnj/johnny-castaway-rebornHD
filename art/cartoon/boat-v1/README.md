# Cartoon motorboat draft

BOAT.BMP000 is an independent boat drawing, with no embedded Johnny. The new raw artwork is awaiting visual approval in the [combined prop review](../props-batch-v1/review.html). It follows the original broadside silhouette with a red cabin, ivory hull, stern ladder and bow railing. The exact approved palm supplies the Cartoon outline and shading reference.

The exact built-in ImageGen request and unchanged returned PNG are under `generation/`; `generation/record.json` records actual dimensions, alpha and hashes. `reference/source.json` binds the supplied original, current HD proxy and style PNG. Original diagnostic colors are not verified original-executable colors.

Static resource mapping attributes BOAT000 to GJNAT3 and WOULDBE actions, including boat arrivals, stops and departures. This is source attribution, not a fresh native scene capture. The original canvas is248x61 and the runtime target is496x122. Final uniform-scale registration, interaction fit and native motion remain pending.

The current art-first workflow defers full smoke/regression and integration audit. No production package, art catalog or engine was changed for this draft.

Export note: the raw alpha channel contains faint values below8 outside the visible boat. The alpha>=8 bounds are(92,197)-(1893,613); the any-alpha bounds are(90,71)-(1895,766). Preserve the raw file and choose registration against the original geometry rather than letting nearly transparent specks determine the boat's scale. No alpha cleanup has been applied.
