# Coherent-ground native still adapter

This is a new preview version. `../native/` and its rejected-strip evidence are
immutable. The adapter imports that pinned capture helper and reuses its exact
observation-only driver, native build, ordered smoke/repeat sequence and codec.
It does not change engine code, timing, placement, sprite canvas or transforms.

The baseline is production plus the exact four V5 holiday PNGs. Replaying
`../native/prepare.py` recreates those payloads; ZIP timestamp differences are
allowed. The proposed package must change exactly BACKGRND000 and003–011,
retaining all2588 other baseline payloads and all original member names/canvases.
The ten replacements are a single coherent-master export, not independently
scaled decorations. Exporter/master/foam source binding remains in the sibling
authoring report; preparation records every runtime path and hash used.

The same native no-decoration, clover, pumpkin and tree cases run at normal
high-tide/day/zero-offset setup. Eight smokes precede eight fresh-process repeats.
The normal six-tick A wait still draws modified000/003/007/009 only. All ten
files are loaded, but loading does not establish motion coverage for the other
six phases. Pixel differences are allowed only inside the four actually drawn
canvases. Actual base origin, wave identities and selected paths are checked.

The previous phase probe and native images remain authoritative for that exact
initialization; this version does not force a wave tuple. Each new capture logs
the real BACKGRND draws again. New actual-input controls alter base origin,
final wave identity and a pixel outside the ground; untouched positives run
before and after. This does not judge ground joins, alpha accumulation, foam
occlusion, all-phase continuity, low tide, offsets or story execution.

## Run after the master exports are ready

`--runtime-root` is a directory containing the ten selected
`BMP/BACKGRND.BMP/NNN.png` files. Use fresh output names. Keep the old production
baseline at this historical revision when replaying after eventual promotion.

```text
python -B art/cartoon/shoreline-repair-v1/native-v2/prepare.py --baseline build/shoreline-repair-v1/selected-v1/baseline.zip --runtime-root <selected-master-export-directory> --output build/shoreline-repair-v1/selected-master-v1
python -B art/cartoon/shoreline-repair-v1/native-v2/run.py --baseline build/shoreline-repair-v1/selected-v1/baseline.zip --candidate build/shoreline-repair-v1/selected-master-v1/candidate.zip --output build/shoreline-repair-v1/native-master-v1
```

The isolated launch retains the pinned local Docker image, network disabled,
read-only source mount, fresh writable output, `--init` and Xvfb. It never opens
a host desktop window. Cleanup targets only its unique container and verifies
absence. Actual source hashes, commands and any failure logs are retained.

Focused helper checks use the prior observed phase log and temporary package
fixtures. No candidate master images or native captures are needed for these:

```text
python -B art/cartoon/shoreline-repair-v1/native-v2/check.py --baseline build/shoreline-repair-v1/selected-v1/baseline.zip --phase-probe build/shoreline-repair-v1/phase-probe-v1/captures/phase-probe --phase smoke --report build/shoreline-repair-v1/native-v2-toolchecks/smoke.json
```

The positive pixel fixture exercises a point inside000 but outside all waves.
