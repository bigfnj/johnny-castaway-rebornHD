# Art authoring records

Start with [image authoring lessons](../docs/art-style-learnings.md) before
creating another style pack. It links approved work, failed approaches, engine
constraints and reproducible export records from the Cartoon pilot. The
[runtime and packaging guide](../docs/cartoon-art.md) describes the current
HD/Cartoon implementation and offline tools.

Keep each style's identity guide, source ancestry, exact prompts, export recipe,
validation evidence and scoped human acceptance together. Preserve useful
negative results as lessons. Working previews can live in ignored build
directories; selected art and reusable knowledge need durable records here.
